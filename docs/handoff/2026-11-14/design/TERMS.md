# 화면 용어 기준 (디자인팀)

사용자 결정(2026-11-15): AIDA 용어 사전은 쓰지 않는다. 화면에 쓰는 말의 기준은 이 문서, 화면 문구(user-env/i18n), 설계 문서 본문이다. 문구를 새로 쓰거나 고칠 때 이 문서를 먼저 본다.

## 분석, 스캔, 검사

| 말 | 뜻 | 쓰는 곳 | 영어 |
| --- | --- | --- | --- |
| 분석 | 사용자가 시작하고 결과를 얻는 일 | 시작, 다시 하기, 대상, 범위, 결과. 분석 시작, 다시 분석, 분석 대상, 분석 범위, 분석 결과, 먼저 분석 | analysis, analyze |
| 스캔 | 분석 안에서 파일 정보를 읽어 들이는 실행 | 진행 상태와 그 제어, 그 실행이 남긴 것. 스캔 중, 스캔 일시 중지, 스캔 계속, 스캔 취소, 스캔 완료, 스캔 문제, 스캔한 폴더, 스캔 기록 | scan |
| 검사 | 값이나 파일이 맞는지 확인하는 일 | 무결성 검사, 유효성 검사, 중복 검사에만 쓴다 | check, validation |

- "검사"를 스캔이나 분석의 뜻으로 쓰지 않는다. "스캔 시작"을 누른 사람이 결과에서 "검사 문제"를 보면 다른 검사가 따로 돌았다고 읽는다.
- "스캔 범위"라고 쓰지 않는다. 범위에 꾸밈말을 붙일 때는 "분석 범위"다(분석 범위 검토, 분석 범위 밖). 문맥이 분명한 곳의 꾸밈말 없는 "범위"(범위를 다시 검토하세요, 저장된 범위)는 괜찮다. 영어는 scope 하나로 쓰고, range는 날짜 범위, 수치 범위, 쪽 구간에만 쓴다.
- 결과는 "분석 결과"다. "스캔 결과"라고 쓰지 않는다. 폴더 하나나 스캔 전체의 읽기가 끝난 것은 "스캔"으로 쓴다(스캔 완료, 스캔을 마친 폴더, 스캔이 이미 끝났습니다). 표지 "스캔 완료"와 같은 일을 "분석이 끝났습니다"라고 쓰지 않는다.
- 사용자가 누르는 시작 단추는 "분석 시작"이고, 누른 뒤의 상태 표지는 "스캔 중"이다. 일시 중지, 계속, 취소는 스캔에 하는 동작이므로 "스캔 일시 중지", "스캔 계속", "스캔 취소"다.
- 낱말 하나짜리 "검사"를 단추나 메뉴 이름으로 쓰지 않는다. 항목의 자세한 정보를 여는 동작은 "상세 보기" / "View details"다(폴더 상세 보기, 항목 상세).

## 그 밖에 맞춘 말

| 말 | 뜻과 쓰임 | 쓰지 않는 말 |
| --- | --- | --- |
| 먼저 분석 | 스캔 중에 고른 폴더를 앞당겨 읽게 하는 요청. 행 상태는 "먼저 분석 요청됨" | 우선 수집, 우선 스캔 |
| 이 폴더만 보기 | 그래프와 표의 범위를 고른 폴더로 좁히는 동작 | 드릴다운 |
| 펼치기, 한 단계 접기 | 그래프에서 폴더를 제자리에서 한 단계 더 그리거나 되돌리는 동작. 범위는 바뀌지 않는다 | 드릴다운 |
| 기타 {n}개 | 작은 항목을 합친 묶음의 이름. 영어는 "Other ({n})" | 나머지, 그 외 |
| 그래프 | 트리맵, 막대 그래프 같은 그림 전체를 가리키는 말. 영어는 chart | 시각화(설계 문서에서만 쓴다), 영어의 visualization, graph |
| 묶음 | 그래프가 작은 항목을 합친 것. 안에 든 것은 "묶인 항목". 영어는 combined items | 그룹(그룹은 사용자가 규칙으로 만드는 가상 그룹에만 쓴다) |
| 구간 | 긴 목록을 나눠 읽는 한 토막. 다음 구간, 이전 구간 | 범위(범위는 분석 범위에만 쓴다) |
| 최종, 중간 결과, 누락이 있는 최종 결과, 취소됨 | 결과 판의 이름. 분석 화면 머리와 그래프의 근거 표가 같은 말을 쓴다. 이름표 없이 서는 배지에서는 "스캔 중 · 중간 결과", "누락 있음", "스캔 취소됨"으로 쓰고, 최종이면 배지를 두지 않는다 | 완전한 결과, 부분 결과 |
| 현재 분석 | 결과의 출처가 지금 한 분석이라는 뜻 | 출처를 "스캔"이라고 쓰지 않는다 |
| 분석 결과, 스캔 기록 | 항목 상세의 "출처" 줄. 결과에 든 항목은 "분석 결과", 스캔이 남긴 기록뿐인 항목은 "스캔 기록". 영어는 Analysis result, Scan record | 출처 줄의 "스캔" |
| 접근할 수 없는 범위, 읽지 못한 범위 | 분석 범위 가운데 읽지 못한 곳. 영어는 Inaccessible locations, Unread locations | 영어의 ranges, scope |
| 확인 불가 | 값을 알아낼 수 없다는 뜻. 영어는 Unavailable | 사용할 수 없음(값을 가리킬 때) |
| 계산 중… | 스캔 중이라 값이 아직 없다는 뜻. 끝까지 나오지 않을 값에는 쓰지 않는다. 영어는 Calculating… | 확인 불가(아직 없을 뿐인 값에) |
| 따라가지 않은 링크 | 스캔이 안으로 들어가지 않은 링크. 영어는 Link (not followed) | 탐색되지 않은 링크 |
| 상세 보기, 상세 정보, 상세 닫기 | 항목이나 값의 자세한 내용을 여는 단추, 그 제목, 닫는 단추 | 세부 정보 |
| 알 수 없음 | 화면이 모르는 값을 받았을 때의 말. 영어는 Unknown. 내부 값을 그대로 보이지 않는다 | 확인할 수 없는 값 |
| 최소값, 최소 {값} | 실제 값이 이보다 크거나 같다는 뜻 | 하한(설계 문서에서만 쓴다) |
| 중복 없는 실제 크기 | 같은 내용을 한 번만 센 크기 | 고유 실제 공간, 고유 물리 크기, 고유 물리적 크기 |
| 지금 반영 | 미뤄 둔 새 결과를 화면에 반영하는 단추 | 새로 고침, 갱신 |
| 최신 결과 보기 | 진행 중인 스캔이 아닌 결과를 보는 동안 다른 분석의 새 결과로 바꾸는 단추 | 새 판으로 갱신 |
