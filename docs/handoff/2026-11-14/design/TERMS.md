# 화면 용어 기준 (디자인팀)

사용자 결정(2026-11-15): AIDA 용어 사전은 쓰지 않는다. 화면에 쓰는 말의 기준은 이 문서, 화면 문구(user-env/i18n), 설계 문서 본문이다. 문구를 새로 쓰거나 고칠 때 이 문서를 먼저 본다.

## 분석, 스캔, 검사

| 말 | 뜻 | 쓰는 곳 | 영어 |
| --- | --- | --- | --- |
| 분석 | 사용자가 시작하고 결과를 얻는 일 | 시작, 다시 하기, 대상, 범위, 결과. 분석 시작, 다시 분석, 분석 대상, 분석 범위, 분석 결과, 먼저 분석 | analysis, analyze |
| 스캔 | 분석 안에서 파일 정보를 읽어 들이는 실행 | 진행 상태와 그 제어, 그 실행이 남긴 것. 스캔 중, 스캔 일시 중지, 스캔 계속, 스캔 취소, 스캔 완료, 스캔 문제, 스캔한 폴더, 스캔 기록 | scan |
| 검사 | 값이나 파일이 맞는지 확인하는 일 | 무결성 검사, 유효성 검사, 중복 검사에만 쓴다 | check, validation |

- "검사"를 스캔이나 분석의 뜻으로 쓰지 않는다. "스캔 시작"을 누른 사람이 결과에서 "검사 문제"를 보면 다른 검사가 따로 돌았다고 읽는다.
- "범위"에는 항상 "분석"이 붙는다(분석 범위, 분석 범위 밖). "스캔 범위"라고 쓰지 않는다.
- 사용자가 누르는 시작 단추는 "분석 시작"이고, 누른 뒤의 상태 표지는 "스캔 중"이다. 일시 중지, 계속, 취소는 스캔에 하는 동작이므로 "스캔 일시 중지", "스캔 계속", "스캔 취소"다.
- 낱말 하나짜리 "검사"를 단추나 메뉴 이름으로 쓰지 않는다. 항목의 자세한 정보를 여는 동작은 "상세 보기" / "View details"다(폴더 상세 보기, 항목 상세).

## 그 밖에 맞춘 말

| 말 | 뜻과 쓰임 | 쓰지 않는 말 |
| --- | --- | --- |
| 먼저 분석 | 스캔 중에 고른 폴더를 앞당겨 읽게 하는 요청. 행 상태는 "먼저 분석 요청됨" | 우선 수집, 우선 스캔 |
| 이 폴더만 보기 | 그래프와 표의 범위를 고른 폴더로 좁히는 동작 | 드릴다운 |
| 펼치기, 한 단계 접기 | 그래프에서 폴더를 제자리에서 한 단계 더 그리거나 되돌리는 동작. 범위는 바뀌지 않는다 | 드릴다운 |
| 기타 {n}개 | 작은 항목을 합친 묶음의 이름. 영어는 "Other ({n})" | 나머지, 그 외 |
| 지금 반영 | 미뤄 둔 새 결과를 화면에 반영하는 단추 | 새로 고침, 갱신 |
| 최신 결과 보기 | 진행 중인 스캔이 아닌 결과를 보는 동안 다른 분석의 새 결과로 바꾸는 단추 | 새 판으로 갱신 |
