## 보드에 그려진 것

groups 보드는 「가상 그룹 보기」 결과 표시 상태 한 장이다. 「그룹 규칙 편집기」 보드는 없다.

위에서 아래로:

1. 제목 "내 기준으로 묶어 보기", 부제 "가상 그룹은 파일의 원래 위치를 바꾸지 않습니다."
2. 한 줄 패널: "규칙: 유형 + 역할 + 태그 | 그룹 / 겹침 / 미분류 / 판정 불가". 왼쪽이 적용 중인 분류 조건, 오른쪽이 범주 탭이다.
3. 그룹 요약 표. 열은 가상 그룹 · 구성원 · 크기 · 중복 소속 · 판정. 예시 행은 개인 동영상(126개, 138.4 GB, 12개, 추정 역할 포함), 보관 자료(842개, 94.0 GB, 38개, 태그 기준), 미분류(3,120개, 18.2 GB, —, 조건 불일치). 첫 행이 선택되어 있다.
4. 통합 합계 설명: "통합 합계는 겹치는 항목을 한 번만 셉니다. 구성원에는 원래 경로를 항상 표시합니다."
5. 동작 줄: 왼쪽 "탐색으로 돌아가기", 오른쪽 "구성원 목록"(기본 동작).

UX 계약 05의 가상 그룹 문장: "유형·역할·태그 규칙으로 구성. 원래 경로를 항상 표시. 겹침/미분류/판정 불가 별도 탭. 통합 합계는 중복 소속을 한 번만 합산. 규칙 변경 후 재분류 필요 표시."

## 가상 그룹 보기 · 영역과 초점 순서 (글로 정함)

초점은 아래 번호 순서로 이동한다.

| 순서 | 영역 | 내용 | 공통 컴포넌트 |
| --- | --- | --- | --- |
| 1 | 머리 | 제목, 부제, 대상 결과의 관측 시각과 완전성 | `ReviewSurface`, `Heading`, `Text` |
| 2 | 분류 조건 줄 | 적용 중인 규칙 이름과 판. 오른쪽에 "규칙 편집" | `Readout`, `Action`(secondary) |
| 3 | 제한 표지 줄 | 부분 결과, 상한 도달, 판정 불가 항목 수 등. 없으면 줄 자체를 그리지 않는다 | `Notice`(info) 또는 `StatusBadge` 묶음 |
| 4 | 범주 탭 | 그룹들 · 겹침 · 미분류 · 판정 불가. 각 탭에 개수 | `ChoiceGroup`/`Choice` (탭 전용 부품 없음) |
| 5 | 그룹 요약 표 | 보드의 다섯 열. 크기는 원시 바이트로 정렬, 모르는 값은 끝 | `DataTable` |
| 6 | 구성원 목록 | 선택한 그룹의 항목. 이름과 **원래 경로**를 항상 보인다. 넓은 창은 표 오른쪽, 좁은 창은 표 아래 | `BrowseGrid`, `ItemActions` |
| 7 | 분류 근거 패널 | 선택한 항목이 그 그룹에 든 이유(일치한 조건) | `DetailDisclosure`, `Readout` |
| 8 | 통합 합계 줄 | 겹침을 한 번만 센 합계와 그 설명. F03 합계와 같은 크기 기준·단위를 쓰고, 하한이면 "이상"을 붙인다 | `Metric`, `Text`(muted) |
| 9 | 동작 줄 | "탐색으로 돌아가기", "구성원 목록" | `Action` |

상태별 표시:

| 상태 | 표시 | 공통 컴포넌트 |
| --- | --- | --- |
| 분류 전 | 조건 줄과 "분류 시작" 단추만. 표 자리는 비워 둔다 | `Action`(primary) |
| 분류 중 | 표 자리에 진행 표시. 이전 결과가 있으면 남기고 "이전 분류"라고 밝힌다 | `Progress`, `LiveStatus` |
| 결과 표시 | 보드와 같다 | 위 표 |
| 빈 결과 | "이 규칙에 해당하는 항목이 없습니다." 오류와 다른 문구 | `ContentState` 또는 `Notice`(info) |
| 판정할 수 없는 규칙 | 조건 줄 아래 띠: "등록되지 않은 조건이 있어 일부 항목을 판정할 수 없습니다." 해당 항목은 "판정 불가" 탭에 모은다. 0건으로 세지 않는다 | `Notice`(info), `StatusBadge`(neutral) |
| 갱신 가능 | "새 결과가 있습니다. 다시 분류" 단추. 자동으로 바꾸지 않는다 | `Notice`(info) + `Action` |
| 재조회 필요 | 규칙이나 결과 판이 바뀜. 받은 표는 남기고 "이전 판" 표지, "다시 분류" | `Notice`(info), `StatusBadge` |
| 적용 불가 | 대상 결과에 필요한 자료가 없음. 사유와 "탐색으로 돌아가기" | `Notice`(info) |
| 오류 | 사유와 "다시 시도". 받은 결과는 남긴다 | `Notice`(error), `Action` |

## 그룹 규칙 편집기 · 영역과 초점 순서 (글로 정함, 보드 없음)

`InspectionDialog`가 아니라 같은 화면 안의 편집 영역으로 연다. 저장이 있는 화면이어서 읽기 전용 점검 대화상자 패턴과 맞지 않는다.

| 순서 | 영역 | 내용 | 공통 컴포넌트 |
| --- | --- | --- | --- |
| 1 | 머리 | "그룹 규칙 편집", 규칙 판 정보(판 번호, 마지막 저장 시각) | `ReviewSurface`, `Heading`, `Readout` |
| 2 | 규칙 목록 | 그룹 이름 목록. 추가, 이름 바꾸기, 삭제, 순서 | `DataTable` 또는 `ChoiceGroup`, `ItemActions` |
| 3 | 조건 편집 | 선택한 그룹의 조건. 0.0.1은 이름 · 유형 · 크기 세 가지만 고를 수 있다 | `ReviewField`, `SelectField`, `ReviewSection` |
| 4 | 판정 불가 조건 | 등록되지 않은 조건은 읽기 전용으로 남기고 "판정 불가" 표지와 사유를 붙인다. 지우지 않는다 | `StatusBadge`(neutral), `Text`(muted) |
| 5 | 알림 | 입력 오류, 충돌, 저장 실패 | `Notice` |
| 6 | 확정·취소 | "저장"(기본 동작), "취소" | `Action`, 버릴 변경이 있으면 `ConfirmDialog` |

상태별 표시:

- **입력 오류**: 해당 입력 아래에 문구(예: "최솟값은 최댓값보다 작아야 합니다"). 저장 단추는 비활성이고 사유를 보인다.
- **저장 중**: 저장 단추가 진행 상태가 되고 크기를 유지한다. 입력은 잠근다.
- **충돌**: 다른 곳에서 규칙이 바뀜. 띠로 알리고 "최신 규칙 불러오기"와 "내 변경 유지하고 다시 검토"를 준다. 내 입력을 지우지 않는다.
- **저장 거절·실패**: 사유를 띠로 보이고 입력을 그대로 둔다. "다시 시도".
- **저장 완료**: 편집 영역을 닫고 보기 화면에 "규칙이 바뀌어 다시 분류해야 합니다" 표시.

## 진입점과 복귀

- 위치: 탐색 화면(BrowsePanel) 동작 줄에서 "분석으로 돌아가기"와 시각화 단추 옆. 보조 단추로 둔다.
- 문구: "가상 그룹으로 보기" / "View as virtual groups". 화면 제목은 보드대로 "내 기준으로 묶어 보기" / "Group by my rules".
- 닫기: "탐색으로 돌아가기" / "Back to folders". 돌아가면 같은 결과 판, 같은 폴더 위치, 같은 선택과 스크롤이며, 초점은 진입 단추에 놓인다. Esc는 편집 영역이 열려 있으면 그것만 닫는다.
- 작업공간 셸 재설계에서 위치가 바뀌면 디자인팀이 알린다.

## 새로 필요한 부품

- **가상 그룹 표지**: 실제 폴더가 아님을 알리는 표지. 지금은 `StatusBadge`(info) "가상 그룹"으로 대신한다.
- **다중 소속 표지**: 한 항목이 여러 그룹에 속함. `StatusBadge`(neutral) "그룹 n개"로 대신하고, 눌러서 소속 그룹을 볼 수 있어야 한다.
- **제한 표지 줄**: 여러 제한을 한 줄에 나열하는 부품이 없다. `StatusBadge` 묶음으로 대신한다.
- **범주 탭**: 탭 전용 공통 컴포넌트가 없다. `ChoiceGroup`으로 대신하면 탭 역할(role)이 아니므로, 탭 부품을 공통으로 두는 편이 맞다.

위 네 가지는 색만으로 구분하지 않고 문구를 함께 쓴다.

## 공통 규칙 (UX 계약 11, 공통 컴포넌트 보드)

- 상태는 색 + 기호 + 문구로 구분한다. 색만으로 구분하지 않는다.
- 빈 결과, 확인 불가, 오류는 서로 다른 문구로 쓴다. 모르는 값을 0으로 쓰지 않는다.
- 대화상자는 초점이 안에서 순환하고 Esc로 닫히며, 닫으면 연 단추로 초점이 돌아간다. 사라진 행이면 가까운 유효 행으로 간다.
- 초점 테두리는 2px로 보이고 선택 표시와 다른 모양이다.
- 기본 동작은 한 영역에 하나만 강조한다. 비활성 단추는 사유를 함께 보인다. 불러오는 동안 크기를 유지한다.
- 진행 막대는 실제 값만 반영한다. 총량을 모르면 불확정 막대와 개수만 보인다.
- 중요한 오류는 사라지지 않는 띠로 보인다.
- 644×461 창과 300% 확대에서는 한 열로 흐르고 가로 스크롤이 생기지 않아야 한다. 긴 이름과 경로는 줄바꿈하거나 가운데를 줄인다.

좁은 폭과 300% 확대에서 F36은 다음 순서의 한 열로 흐른다: 머리 → 조건 줄 → 제한 표지 → 탭 → 요약 표 → 구성원 목록 → 근거 → 합계 → 동작. 요약 표는 열을 줄이지 않고 행을 줄바꿈한다.
